- [ ] **Step 2: Add the repository-owned fuzz runner**

Create `scripts/fuzz-smoke.sh` with this contract:

```bash
#!/usr/bin/env bash
set -euo pipefail

fuzztime="${FUZZTIME:-2s}"
minimizetime="${FUZZMINIMIZETIME:-1x}"
parallel="${FUZZ_PARALLEL:-1}"

packages="$(go list ./...)"

while IFS= read -r package; do
    targets="$(go test "$package" -list '^Fuzz')"
    while IFS= read -r target; do
        case "$target" in
        Fuzz*)
            printf '== %s %s ==\n' "$package" "$target"
            go test "$package" -run '^$' -fuzz "^${target}$" \
                -fuzztime "$fuzztime" -fuzzminimizetime "$minimizetime" \
                -parallel "$parallel"
            ;;
        esac
    done <<<"$targets"
done <<<"$packages"
```

The script must fail on the first target failure and must not hard-code the current target list, so future fuzz functions are automatically included.
Package and target discovery must be captured before iteration so their exit
statuses are not lost through Bash process substitutions.

- [ ] **Step 3: Validate the runner locally**

Run:

```bash

FUZZTIME=1x FUZZMINIMIZETIME=1x FUZZ_PARALLEL=1 scripts/fuzz-smoke.sh
```

Expected: every discovered fuzz target executes one generated input and all packages pass.

- [ ] **Step 4: Add the Linux fuzz CI job**

Add this job to `.github/workflows/go.yml` after `test-linux-race`:

```yaml

    name: test-linux fuzz
    runs-on: ubuntu-24.04
    timeout-minutes: 20
    steps:
      - name: Checkout
        uses: actions/checkout@v7.0.1

      - name: Fuzz smoke

```
